# MISS HIGHNESS SALES DASHBOARD
![Screenshot 2025-02-07 152643](https://github.com/user-attachments/assets/ddc68387-13fc-456f-b7d7-58b29de44b17)

Miss Highness is the one-stop online destination for traditional & Classy Designer Fashion Jewellery. At Miss Highness, you would find a diverse collection of premium quality fashion jewelry. So, the Miss Highness Sales Dashboard is an interactive Power BI report designed to monitor and analyze order performance across different states and cities. It features dynamic filters, geographical mapping, and insightful visualizations that track monthly order trends, delivery statuses, and key metrics such as total orders and top-performing locations. By integrating multiple visual elements—bar charts, line graphs, donut charts, and KPI cards—the dashboard empowers stakeholders with real-time insights to support data-driven decision-making and improve operational efficiency.
